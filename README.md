# Theme Vault · 酒馆图床离线保险箱 (Android)

专为 **TT 酒馆** 安卓手机用户打造的极简现代风格原生 APP（Kotlin + Material 3）：
**一次授权美化文件夹 → 后台锁屏批量缓存去重 → 日后挂图秒搜 & 一键换链/压缩复活 → 内置 GitHub Releases 远程自动更新。**

## ✨ 核心特性

1. **极简现代暗黑 UI**：大圆角留白卡片、自定义矢量图标、无冗余视觉干扰。
2. **原生目录授权（兼容安卓 8~15）**：选中美化文件夹后自动递归扫描 `.json` / `.css` / `.txt` / `.html`（以及角色卡 `.png` 内嵌美化），全局自动去重。
3. **前台通知栏并发缓存**：6 线程并发 + 自动防盗链重试 + 图片魔数校验 + 每 15 张自动保存断点，切回 TT 酒馆或锁屏不断。
4. **三种智能复活策略（兼顾轻量与永久）**：
   - **转存 Catbox 换新链（默认推荐）**：把保险箱里缓存好的原图重新上传并替换成新外链，**美化文件依然只有几 KB，绝不拖慢 TT 酒馆加载速度**！
   - **WebP 压缩内嵌 Base64**：内置原生 WebP 压缩（体积缩小 70%+，自动跳过 GIF 保留动画），彻底离线永不失效，适合小图/轻量美化。
   - **本地路径替换**：批量替换为 `/user/images/vault/` 前缀。
5. **应用内远程自动更新（OTA）**：
   - 绑定仓库：`cone97218-alt/pic`
   - 每次推送新代码（修改 `app/build.gradle.kts` 中的 `versionName`），GitHub Actions 自动编译并发布 Release；在 APP 右上角点 **「更新」** 即可自动下载最新版本 APK 并拉起系统安装（内置国内下载镜像自动回退）。

## 🚀 自动编译与发版

将本目录推送到 `https://github.com/cone97218-alt/pic` 的 `main` 分支后：
1. 打开仓库 **Actions** 页，等待约 2 分钟自动构建完成。
2. 在仓库右侧 **Releases** 中直接下载 `STThemeVault-v1.0.0.apk` 安装到安卓手机。
3. 以后每次更新代码并递增 `app/build.gradle.kts` 里的 `versionName`（例如 `1.0.1`），推送后在手机 APP 右上角点「更新」即可一键升级！
